# Habit Tracker

## Description
A simple Python program to manage daily habits
and track their completion status.

## Features
- Add new habits.
- View all habits and their status.
- Mark habits as completed.
- Delete habits.
- Simple menu-driven interface.

## Technologies Used
- Python 3

## Concepts Learned
- Lists and dictionaries
- While loops and conditional statements
- User input
- `enumerate()`, `append()`, and `pop()`
- Exception handling

## Future Improvements
- Save habits in a file.
- Track daily streaks.
- Display habit completion statistics.
